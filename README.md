# Sharp Odds

Tracks pre-match soccer odds from several bookmakers through
[The Odds API](https://the-odds-api.com) (v4), on its free plan of 500 credits
per month. Rounds of matches are picked in a Discovery panel, odds are
snapshotted until kickoff, and each round can be exported as CSV for offline
backtesting.

Status: **in development.** See [`docs/plan.md`](docs/plan.md) for the plan and
credit budget, and [`docs/odds_api_facts.md`](docs/odds_api_facts.md) for the
API facts it is built on.
